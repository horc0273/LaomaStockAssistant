老马智能股票盯盘助手 1.0.0 正式内测版

安装：
1. 双击 LaomaStockAssistant-Setup-1.0.0.exe。
2. 按安装向导完成安装，可选择创建桌面快捷方式。
3. 安装完成后启动软件，浏览器会自动打开工作台。

登录：
- 默认账号：laoma
- 默认密码：maguo591034

数据：
- 每台电脑的自选股、持仓、账号和日志相互隔离。
- 本安装包不包含软件作者的持仓、自选股、Tushare Token 或会员数据库。
- 本地用户数据保存在 %APPDATA%\LaomaStockAssistant，卸载软件时默认保留。

联网：
- 软件需要联网读取行情数据。
- 未配置 Tushare Token 时，会使用腾讯、东方财富等公开数据源。

说明：
- 本软件仅用于内部研究、盯盘和策略验证，不构成投资建议。
- AI动作和量化评分不能替代人工判断，真实交易由使用者自行决定并承担风险。
