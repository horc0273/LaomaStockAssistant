# 做T信号与早盘风险预警设计

## 目标

在不接入真实下单的前提下，把做T机会、隔夜外盘/集合竞价信息和持仓风险线统一呈现在持仓与个股分析界面，并保留可验证的模拟记录。

## 方案

### 后端

- 复用现有分钟行情、企业质量闸门、成本/止盈/止损字段，生成 `t_signal`：适合度、机会分数、支撑/压力、振幅、量比、理由和数据质量。
- 在 dashboard bootstrap 中加入 `morning_briefing`：外盘联动、集合竞价状态、A股板块确认状态和风险结论；只做提示，不生成买入指令。
- 增加 `t_simulation_summary`，只统计已有模拟成交记录；样本不足时明确返回样本不足，不虚构胜率。
- 非正成本、过期或 fallback 行情不得触发“适合做T”。

### 前端

- 持仓表新增做T状态、机会分数和成本/支撑/止盈/止损摘要。
- 今日工作台新增早盘预警卡，展示来源、更新时间和数据质量。
- 个股分析弹窗复用现有做T面板，明确“企业闸门”和“模拟/人工确认”。

### 错误处理

- 任一数据源失败只降级对应模块，显示来源和重试入口。
- 外盘联动缺少数据时显示“仅供参考”，禁止升级为买入建议。

## 验收标准

1. 有效分钟数据和有效成本时能输出做T状态与价格区间。
2. 成本异常或数据过期时状态不能为“适合做T”。
3. 早盘预警显示数据时间和来源，不影响其他页面加载。
4. 没有模拟成交时统计显示“样本不足”。
5. 通过后端单元测试、前端语法检查和现有回归测试。
