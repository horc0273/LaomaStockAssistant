# 选股中枢 2.0：稳定数据源、异动监控、多模型选股与产业链研究设计

日期：2026-06-27
产品：老马智能股票盯盘助手
状态：待用户审阅

## 1. 背景

现有系统已经具备全 A 扫描、智能选股 DSL、AI 配置、推荐验证、数据健康和自选股分析能力。用户希望继续参考 GO-STOCK、视频号截图和两个视频主题，把系统升级为更完整的选股中枢：

- 视频 1：大 A 稳定数据源 skill，核心是数据源稳定、速度快、可降级。
- 视频 2：Serenity / 产业链拆解 skill，核心是从热点拆产业链、找卡点、筛公司、核证据、排优先级。
- 截图 1：异动监控，包括利好/利空异动、实时/历史数据、自动刷新、保存历史和类型筛选。
- 截图 2：更多可选择的形态、指标、人气、连涨、连跌和排名模型。

本设计采用混合数据路线：免费公开源优先跑通全市场，关键能力预留专业数据源插槽。推荐系统不只看涨幅排序，而是合成数据质量、异动、技术模型、资金、概念、产业链证据和 AI 复核。

## 2. 目标

构建一个可持续扩展的“选股中枢 2.0”，让用户可以完成以下闭环：

1. 稳定获取全 A 行情、异动、资金流、公告、研报和概念数据。
2. 在异动监控页快速看到利好/利空信号，并能切换实时、历史和保存记录。
3. 在选股页按更多模型自由组合筛选股票。
4. 在推荐页看到更精准的自选推荐和 AI 推荐，每条推荐都能解释“为什么入选、风险在哪里、什么时候失效”。
5. 在产业链研究台输入主题、事件、概念或股票，输出热点拆链、卡点、候选公司、证据核验和优先级。
6. 把产业链研究结果回流到推荐评分和个股 AI 分析，而不是只作为单独报告。

本功能不承诺收益，不自动下单，不把 AI 结论作为交易指令。

## 3. 非目标

- 不接入自动实盘交易。
- 不抓取或复刻受版权限制的第三方源码、付费数据或私有模型库。
- 不在缺少数据时让 AI 编造行情、公告、研报或资金流。
- 不把所有模型一次性做成完全成熟的量化研究平台；先做可解释、可验证、可迭代的工程版本。

## 4. 总体架构

选股中枢 2.0 分为五层：

1. 数据源网关：统一接入免费源和专业源，记录来源、延迟、新鲜度、降级状态和错误。
2. 异动监控引擎：把行情快照转成利好/利空异动事件，并持久化历史。
3. 多模型选股引擎：扩展现有 `ScreenerService` 的字段、信号和策略 DSL。
4. Serenity 产业链研究引擎：从主题或股票拆出产业链、卡点、证据和候选标的。
5. 推荐评分与 AI 复核：把异动、模型、资金、产业链和 AI 分析合成推荐结果，并进入推荐验证台。

数据流：

```text
公开源/专业源
  -> MarketDataGateway
  -> 行情快照 / 资金流 / 公告研报 / 概念行业
  -> 异动监控 + 多模型选股 + 产业链研究
  -> 推荐评分
  -> AI 复核
  -> 推荐验证台 / 自选股 / 个股 AI 分析
```

## 5. 数据源设计

### 5.1 免费公开源

默认先接这些通道：

- Eastmoney：全 A 批量行情、涨跌幅、成交额、换手、量比、市值、主力净额、行业概念。
- Tencent：指数和个股实时行情备用。
- Sina：基础行情备用。
- Eastmoney 公告/研报/资金流页面接口：作为公开源补充。
- 本地 SQLite/PostgreSQL：保存策略、异动历史、推荐记录、产业链研究结果。
- Redis：缓存实时行情、异动快照和研究中间结果。

每条数据必须带：

```json
{
  "source": "eastmoney",
  "fetched_at": "2026-06-27T10:30:00",
  "latency_ms": 320,
  "freshness_sec": 2,
  "fallback_used": false,
  "stale": false,
  "errors": []
}
```

### 5.2 专业源插槽

预留但不强依赖：

- Tushare Pro：财务、公告、复权日线、基础资料。
- AKShare：备用数据聚合。
- RQData / iFinD / 聚宽：未来可接更稳定的专业行情和财务源。
- 券商 QMT / PTrade：未来只用于持仓和成交回报复盘，不在本期做自动交易。

专业源未配置时，系统仍能工作，但数据健康页要显示能力差异。

### 5.3 降级规则

- 主源失败时切换备用源，并在页面标记 `已降级`。
- 所有源失败时返回明确错误，不返回演示值。
- 非交易时间允许读取最新快照和历史数据，不阻止登录和使用研究功能。
- 数据陈旧时可以展示，但必须标注更新时间和陈旧状态。

## 8. Serenity 产业链研究设计

新增“产业链研究台”，同时把简版结果嵌入推荐详情和个股 AI 分析。

### 8.1 研究流程

Serenity 流程固定为：

1. 热点拆链：把主题拆成上游、中游、下游、设备、材料、服务、应用。
2. 找卡点：找供应瓶颈、价格弹性、技术壁垒、国产替代、产能约束。
3. 筛公司：匹配 A 股公司，标注主营相关度、收入占比可信度和概念热度。
4. 核证据：公告、研报、财报、互动平台、新闻、资金流、异动事件。
5. 排优先级：按产业链位置、证据强度、市场热度、技术形态和风险排序。

### 8.2 输入

- 主题：例如 `AI 算力`、`PCB`、`液冷`、`电力设备`。
- 事件：例如 `英伟达订单增加`、`铜价上涨`、`政策刺激`。
- 股票：例如 `沪电股份`，系统反查产业链位置。
- 自选股组合：系统批量判断哪些自选股与当前热点有关。

### 8.3 输出

```json
{
  "topic": "AI 算力",
  "chain": [
    {"layer": "上游", "items": ["铜箔", "覆铜板", "高速连接器"]},
    {"layer": "中游", "items": ["PCB", "液冷", "电源", "服务器"]},
    {"layer": "下游", "items": ["云厂商", "数据中心", "大模型训练"]}
  ],
  "bottlenecks": [
    {"name": "高端 PCB 产能", "reason": "AI 服务器升级带来层数和材料要求提升"}
  ],
  "candidates": [
    {
      "code": "002463.SZ",
      "name": "沪电股份",
      "role": "高端 PCB",
      "evidence_score": 82,
      "priority": "高",
      "risks": ["估值偏高", "订单节奏需要验证"]
    }
  ]
}
```

### 8.4 AI 使用边界

AI 可以用于结构化整理、解释和复核，但不能凭空补数据。提示词必须要求：

- 缺数据时输出 `数据未返回/需核实`。
- 引用证据时标明来源类型和时间。
- 给出看多、看空和需要验证的点。
- 不输出确定性收益预测。

## 9. 推荐评分设计

推荐评分由多个子分数组成：

- 数据质量分：来源可靠、延迟低、未降级、字段完整。
- 异动分：利好异动数量、强度、持续性、是否历史重复出现。
- 技术模型分：命中模型数量、模型权重、近期胜率。
- 资金分：主力净流入、成交额、换手、量比。
- 行业概念分：板块强度、概念热度、人气排名。
- 产业链分：卡点位置、证据强度、与热点主题相关度。
- 风险闸门分：市场情绪、涨跌停数量、指数强弱、个股高位风险。
- AI 复核分：外部模型基于证据给出的解释质量和风险一致性。

推荐结果分级：

- `强观察`：多维度共振，但仍需触发条件。
- `观察`：有优势信号，等待价格或量能确认。
- `等确认`：证据不足或市场闸门不佳。
- `风险升高`：高位、资金分歧、利空异动或数据质量不足。

每条推荐必须有：

- 入选原因
- 关键证据
- 风险点
- 观察周期
- 触发价
- 失效价
- 数据源状态
- 是否已进入推荐验证台

## 10. 页面设计

### 10.1 异动监控

页面适合高密度表格，不做大面积装饰。顶部是数据状态和刷新控制，中间是异动类型筛选，底部是事件表。

核心交互：

- 勾选异动类型后立即刷新本地结果。
- 实时模式读取最新快照。
- 历史模式读取持久化事件。
- 保存到历史时记录当前筛选条件和数据源状态。
- 点击股票可进入个股详情、AI 分析、加入自选或创建推荐验证。

### 10.2 智能选股

保留现有 `形态选股 / 指标选股 / 推荐验证 / 数据健康`，扩展模型数量。

新增：

- 模型分组折叠。
- 热门策略。
- 我的策略。
- 关键词搜索。
- 组合条件预览。
- 扫描结果里显示命中模型、分数、产业链标签和异动标签。

### 10.3 产业链研究台

入口放在研究中心，也可从推荐详情进入。

界面包含：

- 输入框：主题、事件、股票或自选组合。
- 模式：快速拆解、深度研究、推荐联动。
- 输出区：产业链层级、卡点、候选公司、证据表、风险表、优先级列表。
- 操作：加入候选池、发起 AI 复核、保存研究、导出 Markdown。

### 10.4 推荐中心

现有推荐验证台继续保留。新增推荐解释：

- 推荐评分拆解。
- 异动命中。
- 技术模型命中。
- 产业链位置。
- AI 复核摘要。
- 数据源健康。
- 推荐后 1/3/5/10 日表现。

## 11. API 设计

新增或扩展接口：

- `GET /api/abnormal/catalog`：异动类型目录。
- `GET /api/abnormal/events`：读取实时或历史异动。
- `POST /api/abnormal/snapshot`：保存当前异动结果到历史。
- `GET /api/screener/catalog`：扩展模型目录。
- `POST /api/screener/run`：支持更多 DSL 字段和信号。
- `GET /api/research/industry-chain/catalog`：读取可识别主题和模板。
- `POST /api/research/industry-chain/analyze`：执行产业链拆解。
- `GET /api/research/industry-chain/history`：读取历史研究。
- `POST /api/recommendations/score`：对候选股进行多因子评分。
- `POST /api/recommendations/ai-review`：调用外部模型复核推荐。

所有接口沿用当前登录态。用户数据隔离，管理员才可配置数据源和 AI 提供商。

## 12. 存储设计

新增表或 SQLite fallback：

- `abnormal_events`：异动事件历史。
- `abnormal_snapshots`：一次保存的异动筛选快照。
- `screener_model_runs`：模型扫描任务和参数。
- `industry_chain_reports`：产业链研究报告。
- `industry_chain_candidates`：研究报告里的候选公司。
- `recommendation_scores`：推荐评分明细。

推荐和研究记录都要保存原始快照，后续行情更新不能覆盖当时证据。

## 14. 测试策略

- 单元测试：异动类型、DSL 校验、模型命中、推荐评分、产业链结果结构。
- 契约测试：数据源字段单位、时间、新鲜度、降级状态。
- API 测试：异动列表、模型目录、选股运行、产业链分析、推荐评分。
- 前端语法检查：`node --check static/app.js`。
- Python 编译检查：`python -m compileall app tests desktop_launcher.py`。
- 冒烟测试：登录、数据健康、异动监控、选股扫描、推荐验证、产业链研究。
- 打包验证：生成便携包和安装包，确认默认登录、静态资源版本和核心页面可打开。

## 15. 风险与处理

- 免费源限流：采用缓存、批量接口、降级源和数据健康提示。
- 模型过多导致噪声：用分组、权重和推荐评分收敛，不让所有条件同权。
- AI 过度自信：提示词和结构化输出要求标注缺失数据。
- 产业链证据不稳定：保存证据快照，区分事实、推断和待验证。
- 非交易时间数据不更新：允许登录和历史研究，实时模块标注非交易时间。
- 推荐结果事后污染：推荐快照只追加验证数据，不覆盖原始证据。

## 16. 完成定义

选股中枢 2.0 完成时，用户可以从稳定数据源获取全 A 快照，在异动监控里看到实时/历史异动，在智能选股里组合多种模型筛选股票，在产业链研究台拆解主题和卡点，并把结果回流到推荐评分和 AI 分析。每条推荐都有来源、证据、风险、触发条件和后续验证记录。
